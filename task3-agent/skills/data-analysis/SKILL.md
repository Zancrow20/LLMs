name: data-analysis
description: Дисциплина кодинга для расчётов по таблицам в run_python. Использовать для любого вызова кода
---
1. Сначала прочитать структуру файла кодом: заголовки и 2–3 строки. Колонки не угадывать.
2. Считать по заданию. Стандартная библиотека: `csv`, `statistics`. Pandas нет.
3. Число в ответе должно быть напечатано выводом кода. Нет вывода — нет числа в ответе.
4. Ошибка кода: исправить код по тексту ошибки, перезапустить. Не больше 4 вызовов `run_python` на вопрос.
5. Итог: ответ с числами, затем строка «как считано» (файл, колонки, функция). Без эмодзи.
