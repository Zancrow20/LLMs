---
name: video-analysis
description: Анализ видео — объекты, их число, события. Использовать, когда во входе есть .mp4/.avi/.mov
---
1. Вызвать `detect_video(path, track=True)`. Путь — относительный, из `workspace/`.
2. Число объектов брать из `unique`: сколько разных экземпляров прошло через кадр. Поле `counts` — детекции по кадрам, для «сколько людей» оно завышает.
3. Если `mean_conf` ниже 0.5 — написать в ответе, что уверенность низкая.
4. Длинное видео: сначала вызов с `max_frames=100` для оценки, полный проход — если пользователь просил весь файл.
5. Формат ответа: строка «объект → число», затем 2–3 предложения вывода. Без эмодзи.
