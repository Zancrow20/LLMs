---
name: speech-report
description: Расшифровка аудио и отчёт по речи. Использовать, когда во входе есть .wav/.mp3
---
1. Вызвать `transcribe(path)`, язык указать по запросу пользователя.
2. Если расшифровка на английском — вызвать `sentiment` на тексте или абзацах.
3. Тональность русского текста `sentiment` не оценит: сделать вывод по содержанию и явно пометить «моя оценка».
4. Отчёт: тема одной строкой, 2–3 ключевые фразы из расшифровки, тональность. Без эмодзи.
