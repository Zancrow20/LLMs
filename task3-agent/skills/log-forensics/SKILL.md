---
name: log-forensics
description: Форензика логов безопасности и расчёты по CSV-таблицам в run_python
---
1. Сначала прочитать заголовки и 2–3 строки файла кодом (`csv.DictReader`), не угадывая названия колонок.
2. Посчитать нужные метрики и агрегаты (статусы 401/403, топ IP-адресов, объём трафика `bytes`, среднее/сумму). Использовать стандартную библиотеку (`csv`, `collections`, `statistics`).
3. Каждое число, IP-адрес и имя пользователя в ответе должны быть напечатаны в `stdout` скрипта. Нет в выводе — нет в ответе.
4. При ошибке кода исправить по тексту `stderr` и перезапустить (не более 4 вызовов `run_python`).
5. Итог: ответ с числами из вывода кода, затем строка «как считано» (файл, колонки, фильтр). Без эмодзи.
