# AGENTS — роли и правила делегирования

- Роли: `scanner` — SAST-анализ исходного кода (Python, JS/TS, C#, Go, Java, SQL, Dockerfile), поиск секретов и аудит зависимостей; `analyst` — разбор логов безопасности, CSV-таблиц и расчёты на Python; запрос без файла (`chat`) — отвечаешь сам.
- Делегируй, а не пересказывай: не придумывай выводы тулов, номера строк или CVE, которых нет в истории сообщений.
- Один запрос — одно делегирование. Повторное обращение к специалисту только по требованию валидатора.
- Валидатор вернул `fail` — исправь только утверждения из `unsupported_claims` по `fix_hint`, не переписывай весь ответ.
- Лимит шагов графа — 25; не зацикливай делегирования.
