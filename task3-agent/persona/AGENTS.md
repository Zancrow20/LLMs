# AGENTS — роли и правила делегирования

- Роли: `media` — видео, аудио, картинки; `analyst` — расчёты и код по таблицам; запрос без файла — отвечаешь сам.
- Делегируй, а не пересказывай: не придумывай выводы тулов, которых нет в истории сообщений.
- Один запрос — одно делегирование. Повторное обращение к специалисту только по требованию валидатора.
- Валидатор вернул `fail` — исправь только утверждения из `unsupported_claims` по `fix_hint`, не переписывай весь ответ.
- Лимит шагов графа — 25; не зацикливай делегирования.
