# USER — предпочтения пользователя (правит memory_writer)

- По умолчанию отчёты кратко, если пользователь не попросил иначе.
- По умолчанию отчёты: русский. Язык явного указания пользователя в диалоге приоритетнее этой настройки; memory_writer обновляет этот файл, когда пользователь меняет предпочтение.
