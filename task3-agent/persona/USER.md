# USER — предпочтения пользователя (правит memory_writer)

- По умолчанию отчёты краткие: 2–4 предложения, если пользователь не попросил подробнее.
- По умолчанию отчёты на русском. Язык явного указания пользователя в диалоге и язык его сообщения приоритетнее этой настройки; memory_writer обновляет этот файл, когда пользователь меняет предпочтение.
